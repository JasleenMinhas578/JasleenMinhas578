### 🚀 What I'm Working On

**Enaimco** — Software Developer (Co-op)
I work across cloud infrastructure, backend, and frontend, building things that remove manual work and cut cost.
- Azure Function Apps built end to end with Terraform, along with the RBAC and permissions each use case needs
- A self-serve media pipeline that took a manual process from 3+ hours down to under 5 minutes
- A full end-to-end duplicate-file detection feature and media cleanup that cut storage costs
- Applied AI and LLM tooling (Azure AI Foundry, Claude Code skills and MCP) that automates routine work and helps new developers get up to speed

**Math-MATE** — Full-Stack Developer (LDANL)
An accessible math platform I designed and built on my own for young children who learn differently. I took it from data modeling and backend through an accessible React frontend, testing, and CI/CD. It is now being tested with students at the Learning Disabilities Association of Newfoundland and Labrador.
